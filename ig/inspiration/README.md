# Inspiration inbox

Drop anything you like here and Claude turns it into style DNA for the writer
(patterns only — never copied text):

- **Screenshots** of posts/covers you liked (any .png/.jpg)
- **Links** — paste URLs into any .txt or .md file
- **Text** — a hook you saw, a story idea, a caption that made you stop

Then tell Claude "process the inspiration folder". Claude reads the new files,
distills WHY each one works (hook shape, emotional trigger, story type), and
updates `learned.md`. That file is injected into every future post prompt
automatically — local and cloud — so the system permanently writes more like
what you love.

You can also send posts/links via Telegram anytime; Claude files them here.
