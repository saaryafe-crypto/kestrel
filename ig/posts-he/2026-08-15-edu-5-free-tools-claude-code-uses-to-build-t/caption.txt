שלושה אתרי 3D בחינם, קוד מקור פתוח ופרומפטים מדויקים. אצל סוכנות עיצוב זה היה עולה אלפי דולרים. 🏗️

Claude Code משתמש בחמישה כלים חינמיים לבניית אתרים עם אנימציות 3D מאפס, בלי ניסיון בעיצוב.

Mobbin MCP לרפרנסים חיים מתוך Claude, CollectUI לצילומי מסך של קומפוננטות UI אמיתיות, Kage עם קוד מקור פתוח מלא, Towers בגודל 1-2MB עם תמיכה במובייל, Sketchbook כנקודת ההתחלה השלישית. ועוד הפרומפטים המדויקים שבהם MengTo בנה את שלושת האתרים עם Opus 5.
