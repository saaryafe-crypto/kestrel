# Approved vs rejected — real pairs

The fastest way to hear the register. Read these before writing.

## Approved (published, owner-level)

- Cover, Gmail story (the model for self-reference + concrete detail):
  "כיבית את סריקת ה-AI של Google במחשב? <em>בטלפון היא עדיין דלוקה</em>,
  וה-AI ממשיך לקרוא דפי בנק ומסמכי מס ב-Gmail שלך"
  Why it works: second person, one concrete scary detail (דפי בנק ומסמכי
  מס), spoken question opener, zero newspaper words.

- Kicker, Claude Code post: "בלי עובדים. בלי שעות נוספות."
  Why it works: two short punches, dry, lets the fact scream.

- Owner-dictated headline (Decart deal — the colon shape done right):
  "מאסק בדרך לעסקת ענק בישראל: אקזיט כחול לבן ב7 מיליארד דולר"
  Why it works: Ynet colon shape, "אקזיט כחול לבן" is a phrase only an
  Israeli would write, local pride angle leads.

## Rejected / corrected (English wearing Hebrew words)

- BAD: "המודל הזה מאפשר למשתמשים ליצור ויזואלים מדהימים"
  GOOD: "המודל החדש יוצר תמונות שנראות כמעט אמיתיות"
  Note: "מאפשר למשתמשים" is press-release calque; say what it DOES.

- BAD: "הרובוט הזה לומד תנועות שלקח לך שנים ללמוד, תוך דקות"
  GOOD: "מה שלקח לך שנים ללמוד, הרובוט הזה למד תוך דקות"

- BAD: "הלקוחות שלכם מחכים? לא יותר"
  GOOD: "הלקוחות שלכם מחכים? כבר לא"

- BAD: "החברה עשתה היסטוריה עם ההכרזה"
  GOOD: "שיא חדש: ..." (state the record itself)

The hard test for every line: read it OUT LOUD. If you can hear the
English sentence underneath, rewrite from the story, not from the words.
