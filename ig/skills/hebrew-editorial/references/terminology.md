# Terminology glossary — @ainews.israel

Rule of thumb: the word an Israeli 16-18yo types in WhatsApp wins. Brand
names stay English. When both a Hebrew and English form exist, pick the one
Israeli tech media + teens actually use.

## Use / Avoid

| Use | Avoid | Why |
|---|---|---|
| AI | בינה מלאכותית (as the repeated term) | Israelis say and type "AI"; the Hebrew form is allowed once for flavor |
| כלי AI | פתרון מבוסס בינה מלאכותית | "פתרון" is press-release Hebrew |
| מודל | מודל שפה גדול ממדים | nobody says it; if needed: "מודל שפה" |
| מחולל תמונות | טכנולוגיית יצירת תמונות | say what it does, short |
| צ'אט | שיח / דיאלוג | spoken register |
| אפשר | ניתן ל... | ניתן is newspaper Hebrew |
| אפליקציה | יישומון | nobody under 60 says יישומון |
| סטארטאפ | חברת הזנק | same |
| אקזיט | מכירת החברה (as the headline word) | אקזיט IS the Israeli word for it |
| הייטק | תעשיית הטכנולוגיה | spoken register |
| עובדים יכולים | משתמשים מסוגלים לבצע | calque of "users are able to" |
| ChatGPT, Claude, Gemini | Hebrew transliterations | brand names stay English |
| אילון מאסק, סם אלטמן, מארק צוקרברג | Elon Musk (in headlines) | Hebrew person-name forms per Israeli media; saves an LTR island |
| ג'ף בזוס | ביזוס | shipped mistake, logged |
| דוחות מס | תלושי מס | invented term we shipped once |
| שבר שיא | עשה היסטוריה | calque |
| החליט | לקח החלטה | calque |
| בשורה התחתונה | בסוף היום | calque |
| כבר לא | לא יותר (as a punch ending) | calque, shipped 3.8 |

## Openers that mark AI writing (never open with)

- "בעולם שבו..."
- "תארו לעצמכם..."
- "בעידן ה..."
- "לאחרונה נחשף כי..."

Open with the fact, the person, or the money. Cold open, no throat-clearing.
